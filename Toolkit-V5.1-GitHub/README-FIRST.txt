Toolkit V5.1 - original command-prompt package

Requires Windows 11, Windows PowerShell 5.1 and administrator access.
The console does not require a .NET runtime.

1. Extract the entire ZIP.
2. Open Toolkit-V5.1, right-click Start-Toolkit.cmd and choose Run as administrator.
3. Type A and press Enter to start General Diagnostics.
4. Look for two SAVED: lines with the TXT and JSON report paths.

Reports normally go to Documents\Toolkit-Reports. If Documents is unavailable,
look in %USERPROFILE%\Toolkit-Reports.
