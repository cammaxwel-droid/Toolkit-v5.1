TOOLKIT COMMAND REFERENCE - EXTENDED EDITION (V2)
=====================================================
For Windows 11, including Lenovo ThinkPad T490s.
This EXTENDS the original reference below instead of replacing the commands you already saved.

QUICK USE
- Win+R: use .msc, .cpl, and ms-settings: entries.
- PowerShell: use Get-*, Test-*, Start-Process and other PowerShell expressions.
- Windows Terminal (Admin): needed for some repair/system commands.
- A driver being 'older' does NOT prove it needs replacement.
- 'winget upgrade --all' is for apps, not Windows OS or hardware firmware.
- Firmware/BIOS and SSD firmware updates are intentionally NOT automated.
- Network resets and destructive disk actions are intentionally excluded.

TOOLKIT COMMAND REFERENCE
============================
Made for quick access from Windows 11 Run (Win+R), Command Prompt, or a batch file.
To get an interactive double-click menu, use the companion Control-Centre-V2.txt script (save it as Control-Centre-V2.cmd).

HOW TO USE
----------
1. Press Win+R, paste/type a command, press Enter.
2. Or copy commands into Command Prompt (cmd).
3. Commands starting with 'ms-settings:' open a Windows Settings page via Win+R.
4. To make a single double-click shortcut, create a text file containing an appropriate
   batch command, Save As > Save as type: All Files > filename.cmd.
   A plain .txt file is a reference, NOT an executable script.

RESTART SHELL
-------------
Restart File Explorer AND taskbar (Command Prompt):
  taskkill /f /im explorer.exe & start explorer.exe

This temporarily hides the taskbar and desktop. Open Explorer windows can close.

WINDOWS UPDATES
---------------
Windows Update (check and install offered Windows updates):
  ms-settings:windowsupdate
Windows Update history:
  ms-settings:windowsupdate-history
Optional updates and drivers (inspect before installing):
  ms-settings:windowsupdate-optionalupdates
Windows version and build installed:
  winver
Recently installed Windows hotfixes (partial inventory only; use Command Prompt):
  powershell -NoProfile -Command "Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 12 HotFixID,InstalledOn"

IMPORTANT: 'winver' shows what's currently installed, NOT proof you have the
newest release available. Use Windows Update to check for updates offered to
your device. Feature rollouts and hardware compatibility can affect availability.

APPLICATION UPDATES (WinGet; run in Command Prompt)
----------------------------------------------------
See which supported apps have updates:
  winget upgrade
Upgrade supported apps (may prompt for installation or elevation):
  winget upgrade --all
Check WinGet installed version:
  winget --version

IMPORTANT: WinGet updates apps, NOT the Windows operating system or every driver.

HOTSPOT AND NETWORK DIAGNOSTICS (Command Prompt)
------------------------------------------------
Display connection details, including Wi-Fi link signal (not mobile data strength):
  netsh wlan show interfaces
Display IPs and adapter details:
  ipconfig /all
Test basic Internet connectivity:
  ping 1.1.1.1 -n 4
See if DNS is resolving:
  nslookup microsoft.com
Clear cached DNS lookups (troubleshooting only; not a speed booster):
  ipconfig /flushdns

WINDOWS HEALTH AND REPAIR (ADMINISTRATOR COMMAND PROMPT)
--------------------------------------------------------
Check whether the Windows component store is flagged as corrupt (quick):
  DISM /Online /Cleanup-Image /CheckHealth
Scan the Windows component store (longer check):
  DISM /Online /Cleanup-Image /ScanHealth
Repair Windows component store if damaged (can require internet):
  DISM /Online /Cleanup-Image /RestoreHealth
Check protected system file integrity without repairing:
  sfc /verifyonly
Check and repair protected system files:
  sfc /scannow

Do not run the repair commands just to improve speed. They are troubleshooting
and repair tools, not general performance optimizers. They require administrator
rights. Do not change Windows services or advanced system settings randomly.

FILE EXPLORER / CMD PERMISSIONS REMINDER
----------------------------------------
App file system permissions: ms-settings:privacy-broadfilesystemaccess
Windows Security: ms-settings:windowsdefender
If Windows Security Controlled folder access blocked an app from writing to
Documents or Desktop, the setting is under Windows Security > Virus & threat
protection > Ransomware protection > Manage ransomware protection.
That is a different control from Settings > Privacy & security > File system.

USEFUL TWO-COMMAND REPAIR ORDER - ONLY IF CHECKS FOUND CORRUPTION
========================================================================
# Run in ADMIN PowerShell, one after the other:
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow

Important: Let the first command complete before starting the second.
If DISM fails, note its error and do not assume it repaired Windows.

DOWNLOAD INTEGRITY (POWERSHELL - READ ONLY)
------------------------------------------
# ZIP's central directory must exist; a PK header by itself does NOT mean it is complete:
Add-Type -AssemblyName System.IO.Compression.FileSystem
$zipPath = 'C:\path\to\archive.zip'
$z = [IO.Compression.ZipFile]::OpenRead($zipPath)
try { "ZIP entries: $($z.Entries.Count)" } finally { $z.Dispose() }

# Check full ZIP contents (decompress each item, no files written):
$z = [IO.Compression.ZipFile]::OpenRead($zipPath)
try {
  foreach ($e in $z.Entries) {
    if ($e.Name) {
      $s = $e.Open()
      try { $s.CopyTo([IO.Stream]::Null) } finally { $s.Dispose() }
    }
  }
  'Archive entry streams read without error.'
} finally { $z.Dispose() }

A download can fail despite ping showing 0% packet loss. Downloads may depend
on servers, HTTP transfers, browser handling, or mobile hotspot behaviour.
