WINDOWS 11 KEYBOARD, RUN AND POWER USER SHORTCUTS
================================================
These are WINDOWS shortcuts, not executable scripts. Compatible options can vary.

BASIC WINDOWS
-------------
Win + E                File Explorer
Win + R                Run dialogue
Win + I                Windows Settings
Win + X                Power-user menu (Terminal/Admin and tools)
Ctrl + Shift + Esc     Task Manager
Win + L                Lock PC
Win + D                Show desktop
Win + Tab              Task View
Alt + Tab              Switch windows
Alt + F4               Close focused window (may prompt to save)
Win + V                Clipboard history (turn on if prompted)
Win + Shift + S        Screenshot snipping
Win + H                Voice typing
Win + P                Display/project options
Win + K                Wireless display/cast menu
Win + Z                Snap layouts (where supported)
Win + Ctrl + D         Create virtual desktop
Win + Ctrl + Left/Right Switch virtual desktop
Win + Ctrl + F4        Close current virtual desktop
Win + Ctrl + Shift + B Request graphics-driver/display reset; screen may flash

FILE EXPLORER
-------------
Ctrl + Shift + N        New folder
F2                      Rename selected file
Alt + Enter             File/folder properties
Ctrl + L                Focus address bar
Alt + Up                Parent folder
Alt + Left/Right        Back / forward
Ctrl + A                Select all
Ctrl + C / V / X        Copy / paste / cut
Shift + Delete          Permanently delete (use with care)

BROWSERS
--------
Ctrl + J                Downloads history (Chrome / Edge)
Ctrl + Shift + T        Reopen last closed tab
Ctrl + L                Address bar
Ctrl + W                Close tab
Ctrl + Shift + N        Incognito in Chrome (InPrivate in Edge)

THINKPAD / POWERTOYS
--------------------
F1 at Lenovo logo       BIOS Setup (Fn+F1 depending on hotkey mode)
F12 at Lenovo logo      One-time boot selection
PowerToys Peek           Use shortcut configured under PowerToys > Peek
PowerToys Command Palette  Win + Alt + Space (if enabled)

IMPORTANT
---------
A shortcut launching a settings page does NOT change the setting itself.
Win + Ctrl + Shift + B resets graphics display processing, not a graphics-driver reinstall.
Use Ctrl + Shift + Esc to diagnose Task Manager before terminating any system process.
