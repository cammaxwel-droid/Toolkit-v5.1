TOOLKIT COMMAND REFERENCE - V3
=================================================================
Organized, short descriptions. Use PowerShell 5.1 or Win+R where specified.
This document expands V2; V2 reference with updated product naming is in legacy/.
VIEW=read-only; REPORT=writes file; CHANGE/REPAIR=modifies state.
No firmware flashing, security disabling or destructive disk actions included.

1. DESKTOP & EXPLORER
---------------------
Windows interface, file navigation, taskbar

  [001] Restart File Explorer + taskbar  (CHANGE)
        Reloads Windows shell; open Explorer windows may close.
        Stop-Process -Name explorer -Force; Start-Process explorer.exe

  [002] Open File Explorer  (VIEW)
        Start File Explorer.
        explorer.exe

  [003] Open Documents  (VIEW)
        Uses actual Documents known folder, not username substitution.
        explorer $([Environment]::GetFolderPath("MyDocuments"))

  [004] Open Downloads  (VIEW)
        Open Downloads under the actual user profile.
        explorer "$env:USERPROFILE\Downloads"

  [005] Open Desktop folder  (VIEW)
        Open actual Windows desktop folder.
        Start-Process ([Environment]::GetFolderPath('Desktop'))

  [006] File Explorer options  (VIEW)
        Folders, view and search behaviour.
        control folders

  [007] Taskbar settings  (VIEW)
        Windows taskbar personalization.
        ms-settings:taskbar

  [008] Task Manager  (VIEW)
        Open process and startup inspection tools.
        taskmgr

  [009] Clipboard history settings  (VIEW)
        Inspect clipboard history settings.
        ms-settings:clipboard

  [010] Desktop background  (VIEW)
        Restore a missing desktop wallpaper.
        ms-settings:personalization-background

  [011] Screen display settings  (VIEW)
        Resolution, scaling and monitors.
        ms-settings:display

  [012] Graphics app preferences  (VIEW)
        Select Windows graphics preferences per app.
        ms-settings:display-advancedgraphics

  [013] Default apps  (VIEW)
        Choose Chrome or other default handlers.
        ms-settings:defaultapps

2. UPDATES & SOFTWARE
---------------------
Windows Update and application update discovery

  [014] Windows Update settings  (VIEW)
        Check official OS updates offered to this device.
        ms-settings:windowsupdate

  [015] Windows Update history  (VIEW)
        Review already installed system updates.
        ms-settings:windowsupdate-history

  [016] Optional driver updates  (VIEW)
        Windows Update offers some, not all, hardware drivers.
        ms-settings:windowsupdate-optionalupdates

  [017] Recent hotfix history  (VIEW)
        Get-HotFix is partial, not complete update inventory.
        Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 15 HotFixID,InstalledOn

  [018] WinGet app update scan  (VIEW)
        Lists available app updates. Does NOT update Windows or firmware.
        winget upgrade

  [019] WinGet installed apps  (VIEW)
        Lists supported registered applications.
        winget list

  [020] Update supported apps  (CHANGE)
        Runs WinGet upgrade --all. May prompt/need internet.
        winget upgrade --all

  [021] Installed apps settings  (VIEW)
        Use Modify, Repair or Uninstall only when needed.
        ms-settings:appsfeatures

  [022] Startup apps  (VIEW)
        Disable unwanted app startup, not Windows services.
        ms-settings:startupapps

  [023] WinGet version  (VIEW)
        Check package manager version.
        winget --version

  [024] Microsoft Store library  (VIEW)
        Open Store for apps distributed outside WinGet.
        ms-windows-store:

3. SECURITY & PRIVACY
---------------------
Defender, firewall, TPM, BitLocker, Secure Boot

  [025] Windows Security dashboard  (VIEW)
        Open Windows Security, no toggles changed.
        ms-settings:windowsdefender

  [026] Defender protection status  (VIEW)
        Antivirus state, definitions age and scanning status.
        Get-MpComputerStatus

  [027] Defender configuration  (VIEW)
        Read controlled folder access, PUA and AV preferences.
        Get-MpPreference

  [028] Firewall profile status  (VIEW)
        Firewall enabled states on Domain/Private/Public.
        Get-NetFirewallProfile

  [029] Advanced firewall console  (VIEW)
        View or manage firewall rules in Windows UI.
        wf.msc

  [030] TPM security chip  (VIEW)
        Read presence and readiness. Never clears TPM.
        Get-Tpm

  [031] Secure Boot check  (VIEW)
        Reports enabled/disabled; does not alter BIOS keys.
        Confirm-SecureBootUEFI

  [032] BitLocker C: status  (VIEW)
        View system-drive encryption and protector state.
        manage-bde -status C:

  [033] Recent Defender detections  (VIEW)
        Threat history can require Admin, no changes.
        Get-MpThreatDetection

  [034] Controlled Folder Access settings  (VIEW)
        Open Windows Security to inspect ransomware protection.
        windowsdefender://RansomwareProtection

  [035] Defender quick scan  (CHANGE)
        Starts a security scan; may take time.
        Start-MpScan -ScanType QuickScan

  [036] Update Defender signatures  (CHANGE)
        Downloads current signatures (internet needed).
        Update-MpSignature

  [037] Local security policy  (VIEW)
        Windows 11 Pro security options; view before editing.
        secpol.msc

  [038] Security summary to file  (REPORT)
        Generate a security report in Documents (sensitive; do not post publicly).
        & .\scripts\Security-Report.ps1

4. HARDWARE & DRIVERS
---------------------
Installed device versions; vendor update discovery

  [039] Device Manager  (VIEW)
        Inspect installed drivers and warning codes.
        devmgmt.msc

  [040] Problem devices only  (VIEW)
        Codes may include intentional camera disable.
        Get-PnpDevice | Where-Object Status -eq Error

  [041] All hardware driver inventory  (REPORT)
        Create CSV with installed driver versions. Does not discover newest vendor version.
        & .\scripts\Driver-Inventory.ps1

  [042] Current graphics drivers  (VIEW)
        Versions currently installed.
        Get-CimInstance Win32_VideoController

  [043] Firmware errors  (VIEW)
        Read firmware class warnings only.
        Get-PnpDevice -Class Firmware

  [044] Thunderbolt + Intel ME devices  (VIEW)
        Check interfaces; not actual installed ME firmware version.
        Get-PnpDevice | Where-Object FriendlyName -match "Thunderbolt|Management Engine"

  [045] BIOS version  (VIEW)
        Reads current BIOS reported by firmware.
        Get-CimInstance Win32_BIOS

  [046] CPU and physical memory  (VIEW)
        Read model, cores and installed physical memory.
        Get-CimInstance Win32_ComputerSystem

  [047] Disk firmware + basic health  (VIEW)
        Storage health flag is not a comprehensive diagnostic.
        Get-PhysicalDisk

  [048] Windows optional driver offers  (VIEW)
        Open optional driver update list; review before selecting.
        ms-settings:windowsupdate-optionalupdates

  [049] Lenovo System Update in Start menu  (VIEW)
        Locate Lenovo update tool; do not auto-install firmware.
        Get-StartApps | Where-Object Name -match "Lenovo.*(System Update|Vantage)"

  [050] Driver and software update scan  (REPORT)
        Runs local driver inventory + winget listing; vendor firmware NOT flashed.
        & .\scripts\Update-Scan.ps1

5. PERFORMANCE & POWER
----------------------
RAM, CPU, startup and battery insights

  [051] Top memory processes  (VIEW)
        Per-process working sets; shared memory may double count.
        Get-Process | Sort-Object WorkingSet64 -Descending

  [052] Available and used RAM  (VIEW)
        Windows memory snapshot.
        Get-CimInstance Win32_OperatingSystem

  [053] Resource Monitor  (VIEW)
        Detailed CPU, memory, disk, and network activity.
        resmon

  [054] Reliability Monitor  (VIEW)
        Review app crashes and unsuccessful installs.
        perfmon /rel

  [055] Performance Monitor  (VIEW)
        Counters and diagnostics.
        perfmon

  [056] Startup apps settings  (VIEW)
        Check app sign-in load.
        ms-settings:startupapps

  [057] Current power scheme  (VIEW)
        Read the active Windows power plan.
        powercfg /getactivescheme

  [058] Supported sleep states  (VIEW)
        See available sleep and hibernate modes.
        powercfg /a

  [059] Power requests  (VIEW)
        See programs preventing sleep.
        powercfg /requests

  [060] Battery report  (REPORT)
        Write standard battery-report.html to Documents report folder.
        powercfg /batteryreport /output <file>

  [061] System performance options  (VIEW)
        Windows visual effects and virtual memory configuration.
        SystemPropertiesPerformance.exe

6. HOTSPOT & NETWORK
--------------------
Wi-Fi, DNS, proxy and connectivity checks

  [062] Wi-Fi link signal and rate  (VIEW)
        Shows connection to phone hotspot, NOT mobile tower quality.
        netsh wlan show interfaces

  [063] Wi-Fi adapter capabilities  (VIEW)
        View bands, wireless mode support and driver capabilities.
        netsh wlan show drivers

  [064] IP and DNS configuration  (VIEW)
        View network addressing and DNS.
        ipconfig /all

  [065] Packet loss: 20 pings  (VIEW)
        Sample connectivity to a public IPv4 address.
        ping -n 20 1.1.1.1

  [066] DNS lookup test  (VIEW)
        Check whether example domain resolves.
        nslookup microsoft.com

  [067] WinHTTP proxy  (VIEW)
        Proxy used by some Windows services.
        netsh winhttp show proxy

  [068] DNS server listing  (VIEW)
        Per network interface DNS settings.
        Get-DnsClientServerAddress -AddressFamily IPv4

  [069] Network interfaces and MTU  (VIEW)
        MTU readout; no tuning performed.
        Get-NetIPInterface

  [070] HTTPS connectivity test  (VIEW)
        Tests TCP/443 connectivity, not full file downloads.
        Test-NetConnection microsoft.com -Port 443

  [071] Wi-Fi adapter settings  (VIEW)
        Open network adapter control panel.
        ncpa.cpl

  [072] Advanced network settings  (VIEW)
        Inspect network driver and properties.
        ms-settings:network-advancedsettings

  [073] Flush DNS cache  (CHANGE)
        Clears DNS cache; not a general speed booster.
        ipconfig /flushdns

  [074] Network Troubleshooter  (VIEW)
        Open Windows troubleshoot settings.
        ms-settings:troubleshoot

7. DISKS & DOWNLOADS
--------------------
Storage status and download integrity

  [075] Disk health overview  (VIEW)
        Read reported media health; no repairs performed.
        Get-PhysicalDisk

  [076] Drive free space  (VIEW)
        Physical volume total and available size.
        Get-Volume

  [077] Disk Management UI  (VIEW)
        Inspect volumes; do not repartition casually.
        diskmgmt.msc

  [078] Online disk scan C:  (VIEW)
        chkdsk /scan checks NTFS online; needs elevated access on some systems.
        chkdsk C: /scan

  [079] Recent downloads  (VIEW)
        Recent files under your actual profile.
        Get-ChildItem "$env:USERPROFILE\Downloads"

  [080] Validate ZIP fully  (VIEW)
        Choose ZIP; read/decompress entries without extracting files.
        & .\scripts\Test-ZipIntegrity.ps1

  [081] File SHA256 checksum  (VIEW)
        Choose file, calculate hash. Compare with official hash.
        Get-FileHash -LiteralPath <path> -Algorithm SHA256

  [082] Optimize Drives UI  (VIEW)
        Windows decides SSD trim or HDD defrag as appropriate.
        dfrgui

  [083] Find incomplete downloads  (VIEW)
        Look for Chrome/Edge temporary .crdownload files.
        Get-ChildItem "$env:USERPROFILE\Downloads" -Filter *.crdownload

  [084] Storage settings  (VIEW)
        Manage storage and cleanup through Windows UI.
        ms-settings:storagesense

  [091] Windows Update troubleshooting  (VIEW)

        ms-settings:troubleshoot

        ms-settings:appsfeatures

  [093] Explorer/taskbar shell restart  (CHANGE)

  [094] Display diagnostics  (VIEW)

RUNNER
------
Double-click Start-Toolkit.cmd or open it as administrator for privileged tools.
Inside the menu: category number, tool ID, ?ID for help; S to search; B back.

UPDATE LIMITATIONS
------------------
WinGet compares supported installed APPLICATION versions using WinGet sources.
Device Manager, PnP and WMI reveal installed driver versions, not the latest online manufacturer versions.
Windows Update optional driver list and Lenovo System Update are separate check paths.
Never interpret installed firmware package name as proof of a successful firmware flash.

WINDOWS PROTECTED REPAIR ORDER
------------------------------
Run only if checks indicate corruption; requires Administrator:
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
