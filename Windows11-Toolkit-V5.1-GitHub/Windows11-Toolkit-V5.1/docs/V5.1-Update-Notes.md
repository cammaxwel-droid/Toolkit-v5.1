# V5.1 update notes

V5.1 is an incremental safety/accuracy update of the previously shipped V5, not a different application.

**Most important:** Do not repair a working device merely because Event Viewer lists errors. Correlate timestamps with real symptoms.

**Known example:** A previous V5 report said zero Explorer crashes although an October 16 Event 1000 crash had been observed earlier. The scan now uses text and structured fields, searches seven days, and explicitly says an event may not be present if the log was cleared/rotated. It cannot recover deleted log events.

**Codex Sandbox events:** Where the rendered message is blank, Deep Diagnostics exports available EventData rather than pretending to know the root cause. Errors should be monitored unless Codex functionality is failing.

**SFC VerifyOnly:** Native output redirection and Windows PowerShell 5.1 encoding may make the message unclassifiable. A zero exit code without readable confirmation yields NO DATA and the raw output file path. A target-file SFC verification can be run manually when appropriate.

**Files:** Generated private reports are saved in Documents\Windows11-ToolkitV5-Reports.

**Still required:** Run launcher as Administrator. Live-test the patch on Windows 11 with the included PowerShell parser/self-test first. Keep your previous V5 archive as fallback.
