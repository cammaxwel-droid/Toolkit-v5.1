WINDOWS 11 TOOLKIT V5.1 - COMMAND & MENU REFERENCE
================================================================
Launch Start-Windows-Toolkit.cmd as Administrator (right-click).
Home shortcuts: A General Diagnostics, B Deep Diagnostics, C General Repair, D Deep Repair.
Every V5 workflow check reports PASS/WARNING/ERROR/NO DATA and exports summaries.
Legacy single-action VIEW tools can return no structured data; empty output is NOT an automatic PASS.
This reference is for Windows 11 and Windows PowerShell 5.1.

QUICK POWER SHELL DIAGNOSTIC COMMANDS (READ-ONLY)
----------------------------------------------------------------
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion" | Select DisplayVersion,CurrentBuild,UBR
Get-PnpDevice | Where-Object Status -eq "Error"
Get-PhysicalDisk | Select FriendlyName,HealthStatus,OperationalStatus
Get-Process explorer -ErrorAction SilentlyContinue
Get-MpComputerStatus | Select AntivirusEnabled,RealTimeProtectionEnabled
Get-NetFirewallProfile | Select Name,Enabled
Get-Tpm | Select TpmPresent,TpmReady
Confirm-SecureBootUEFI
manage-bde -status C:
Get-Service Audiosrv,Spooler,wuauserv
winget upgrade  # Read-only app upgrade scan, not Windows OS updates

WINDOWS INTEGRITY (OPTIONAL, READ-ONLY, ADMIN)
----------------------------------------------------------------
DISM.exe /Online /Cleanup-Image /CheckHealth
DISM.exe /Online /Cleanup-Image /ScanHealth
sfc.exe /verifyonly

REPAIR COMMANDS (CHANGE STATE; RUN ONLY WHEN INDICATED)
----------------------------------------------------------------
DISM.exe /Online /Cleanup-Image /RestoreHealth  # component store repair
sfc.exe /scannow  # protected files
ipconfig.exe /flushdns  # clear resolver cache

V5.1 RELIABILITY NOTE
=====================
The main menu and tool IDs remain unchanged. 171 = General Diagnostics,
172 = Deep Diagnostics, 173 = General Repair, 174 = Deep Repair,
175 = Diagnostic Self-Test. Deep Diagnostics saves event-details TXT files
when critical/error events are found. SFC VerifyOnly output is saved separately.

Use read-only diagnostics first. Check current symptoms; historical event logs
may persist after Windows updates, driver removal or application recovery.
